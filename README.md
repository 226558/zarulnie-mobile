# MobileEntry (AGREED) - Вход на мобильную визитку ZARULNIE

Репозиторий содержит только страницу перехода m.zarulnie.ru → https://zarulnie.ru/m/. MP3, тексты, настройки и медиакэш принадлежат основному сайту. JavaScript вызывает location.replace, сохраняя query и hash без добавления лишнего шага в историю; адрес назначения фиксирован и не берётся из параметров ссылки. Без JavaScript работает meta refresh на корень мини-страницы и остаётся обычная ссылка. Это клиентский переход статического GitHub Pages, а не серверный ответ 301.

Перед отдельной публикацией файлы хостинга накладываются из ../../wslots_b4deploy/zarulnie-mobile: CNAME=m.zarulnie.ru и .nojekyll. Основной сайт должен быть предварительно опубликован с /m/. В Pages выбирается ветка master и корень репозитория; настраиваются Custom domain=m.zarulnie.ru и HTTPS. DNS-запись CNAME для m указывает на <владелец репозитория>.github.io без имени репозитория. Создание Git-репозитория и локальный коммит сами по себе не публикуют страницу и не меняют DNS.
